Hodgkin-Huxley Model — Per Muscle Cell
dV/dt = ( −ICa − IK − INCA − Ileak + Imus ) / Cm
ICa = gEGL19 · mCa · (V − ECa)    ECa=+60mV
IK  = gEXP2 · nK² · (V − EK)    EK=−80mV
INCA= gNCA · (V − ENa)          ENa=+50mV
Ilk = glk · (V − Elk)            Elk=−65mV
dmCa/dt = (m∞(V) − mCa) / τCa
dnK/dt = (n∞(V) − nK) / τK(V)
State per cell: [V, mCa, nK]  Total: 96×3 = 288 state vars
